# 模拟考试与口语对话

## 使用方式

进入 `/mock-exam` 选择雅思 Academic、大学英语四级或六级。生成受理后可离开页面，任务在服务端有界队列执行；回到列表可按考试类型/状态筛选、分页。仅在试卷、逐题审核与听力音频全部成功后允许开始计时。

雅思全卷训练 150 分钟；四级 125 分钟；六级 130 分钟。当前为全卷统一计时、分科时长作安排参考，播放器允许暂停/拖动，不是正式考场监考系统。口语在 `/speaking` 独立训练，其评分不并入笔试总分。

非进行中的考试（READY、COMPLETED、FAILED、EVALUATION_FAILED）可确认删除，连同作答、成绩记录一起删除。生成、作答、评估中的记录禁止删除，避免孤儿任务与误删答案；服务器亦验证所有权和状态。媒体文件不会随记录删除自动清理，避免误删复用资源。

## 生成时间估算

真实生成总耗时（含排队、出题、审核和 TTS）存储到首个 section JSON 的 `GenerationDurationSeconds`，与之后答题/评分更新时间隔离，无需新增数据库列。同一用户、同一考试类型的已有成功记录构成样本，已完成或正在作答的记录均可参与。

API 返回 `estimatedReadySeconds` 与 `generationEstimateSamples`。无样本为 0，超过历史平均为 -1，页面明确说明未知/超时，不编造固定剩余一分钟。删除历史记录会减少样本；历史版本没记录耗时的试卷不用于计算。

后台任务目前沿用进程内有界队列，关页面不影响执行，但服务重启不保证任务续跑。过期任务在列表/详情查询时显式标记失败，可重试；这不是跨重启持久任务恢复。

## 四六级题型与成绩

四级听力：3 则新闻（2+2+3 题）、2 段长对话（4+4）、3 篇短文（3+3+4）。六级听力：2 段长对话（4+4）、2 篇短文（3+4）、3 篇讲话/讲座（3+3+4）。均为 25 道四选一；出题后验证稿内分组顺序与 25 道朗读问题，TTS 复用整段录音。

阅读：10 道选词填空（同一 15 词词库）、10 道段落信息匹配、两篇仔细阅读共 10 题。写作与汉译英各一项，翻译单独评估意义忠实、信息完整和英语表达，不按议论文要求评分。

听力前 15 题各占整卷 1%，后 10 题各占 2%；阅读选词每题 0.5%、匹配每题 1%、仔细阅读每题 2%。主观题 0–100 训练分各占 15%。总成绩明确为加权百分制训练成绩，**不等于官方 CET 710 常模成绩**。雅思继续展示原有非官方三技能估分。

## 口语工作流

先准备题目音频，再录音（Part 2 最长 120 秒）；录音转为 16kHz 单声道 WAV，试听确认后提交。ASR 转写 → 确定下一题 → TTS 生成对应考官音频，三步全部成功才原子推进题号。Part 1 的追问由 AI 结合回答生成；Part 2 卡片和 Part 3 配套题使用服务端已选题目，避免模型改题及主题漂移。失败保留当前题号，网页保留未成功提交的录音/文字用于重试；录音草稿不会跨刷新保存。

会话 ID 本地缓存，服务端保存题目、转写、考官追问及音频地址。重复提交同一已处理题号不会重复推进，处理中重复请求不重复排队。使用既有账号调用限制、模型/TTS调度；演示账号不借此调用真实 AI。

目前评估器只接收转写文字，**不测评发音、语音流利度或完整 IELTS Speaking 总分**。仅给出文字连贯性、词汇与语法的非官方训练反馈，并核验引用确实来自用户回答。ASR 失败不使用输入文字或虚构转写兜底，模型/评分校验失败返回中文错误，后台日志包含记录 ID 和失败阶段。

模型返回也必须明确 `isPartial=true`、`assessmentMode=TEXT_ONLY`，不能靠清空违规分数把异常结果转换成成功。至少需要 20 个去重回答中的英文词、三条不同的连续原文证据及中文优点和改进建议；这是拒绝明显不足样本的最低门槛，并不表示这些词数足以做官方评分。词汇与语法提示使用对应的定性维度，文字连贯性不代替口头流利度。

评分器与事实复核器只接收已完成的问答，实际追问优先；缺失提问时仅补对应计划题，未完成的后续题不进入评分上下文。不能因用户没有回答尚未提出的问题而扣分，也不修改原始会话。

真实文本验收可显式设置 `SPEAKING_QUALITY_LIVE=1`、绝对目录 `SPEAKING_QUALITY_OUTPUT_DIR`，运行 `go test ./internal/ai -run '^TestLiveSpeakingQuality$' -v -count=1 -timeout=20m`。四组自编文本覆盖明显错误、发展中、较灵活及充分展开的表达，检查相对区分度、证据和考官追问；单组评估预算与生产一致为四分钟。测试不调用 ASR/TTS，不将这些文本预设为官方定分样本。私有报告不入库、不发布。

评估结果在返回前还要经过独立的事实复核：逐项检查优点、错误、改写建议和评分依据是否能在原始转写中得到支持，区分可选的风格建议与真实错误。复核拒绝后最多一次定向重评；复核不可用、响应不完整或两次仍不通过时直接报错，不返回分数。真实验收的私有报告会保存评估与复核内容，便于排查；不保存请求头、认证信息或供应商错误正文。

## 已验证与验收边界

- Go 全量测试、vet、后端构建；前端构建与 lint。
- GraphQL 所有权/删除状态保护；CET 题型、题数、翻译原文和分值权重；不可用/超时 ETA。
- 内存与 SQLite 下口语并发提交、TTS 失败原子性、ASR 失败、不输出未测评维度的分数。
- 浏览器回归使用拦截 API：后台返回、成绩/删除、口语失败重试与恢复、原有雅思作答保存/到时交卷等。

这些测试不证明真实供应商生成整套试卷的语义质量、录音可懂度或与官方考试等值。上线前仍需真实生成 CET4/CET6 样卷、人工核对题音匹配、真实麦克风 ASR/TTS 验收以及 PostgreSQL 环境回归。F 盘题库未读取或补充。本次不更改生产部署或推送 GitHub。
