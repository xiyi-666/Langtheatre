# LinguaQuest 产品更新日志

用户可从登录页或「我的 → 设置与服务」打开应用内更新日志。发布新版本时，请同步维护：

- `apps/client/package.json` 的 `version`
- `apps/client/src/product.ts` 中的 `currentProductVersion` 和 `releaseNotes`（新版本置顶）
- 本文件中的文字版记录

## V1.0.4 · 2026-09-23

- 修复 Android SDK 初始化和 Linux 服务端交叉编译流程，确保最新版本可以正常生成安装包。
- 改用 GitHub runner 预装 Android SDK，减少 Android 包构建失败。
- 发布前显式下载 Go 模块并验证 amd64、arm64 服务端构建。
- 小程序、Android、Linux、Windows 和 macOS 使用统一版本号。

## V1.0.3 · 2026-09-23

- 新增 IELTS 听力专项训练、题库导入和难度审核流程。
- 新增 AI 考官口语模拟、会话恢复与口语题目独立质量审核。
- 新增 IELTS、CET-4、CET-6 模拟考试和考试结果记录。
- 优化模型传输失败重试、前端导航和小程序版回归测试。
- 发布流程同步构建小程序镜像、Android APK 和 Linux、Windows、macOS 安装包。

## V1.0.1 · 2026-08-02

- 新增仅后端可见的匿名日聚合统计：模型 Token、核心功能使用和导航点击。
- 不保存用户身份、提示词、文章、音频或原始点击流水；统计读取需独立管理员密钥。

## V1.0.0 · 2026-08-02

- 英语、粤语双路线学习，AI 小剧场与阅读材料生成。
- 剧场库角色扮演：中文、粤语、英语语音识别，AI 续聊和 TTS 语音回复。
- 英语写作：IELTS、CET-4、CET-6 限时写作，AI 多维评分和修改建议。
- 角色音色库：提示词设计音色、试听与剧场角色分配。
- 账号安全：用户名或邮箱登录、邮件验证、密码重置和用户名找回。
- 小程序免费公测：前几次 AI 使用免广告，后续以广告支持服务。
